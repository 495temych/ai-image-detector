Is this image real?

An end-to-end MLOps pipeline for classifying images as real or ai-generated. The pipeline is used for versioning, tracking, automation, and deployment of the model.

§ 01 BRIEF

Generative models now produce images that convincingly pass for photographs. Detection is a well-scoped problem — which lets us spend our effort on the operations layer.

In scope

  • Data versioning tied to every run
  • Metrics · params · artifacts tracked per run
  • Model registry with promotion stages
  • CI that retrains · evaluates · registers
  • Packaged serving behind a container

Not in scope

  • State-of-the-art detection accuracy
  • Novel model architecture
  • Adversarial robustness research
