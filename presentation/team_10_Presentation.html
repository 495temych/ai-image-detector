Data Versioning & Tracking

DVC Git MLflow
ZHAW · TSM_MachLeData · Spring 2026 04 / 15
  • DVC (Data Version Control) stores large files (images, .pt weights, .onnx) out of Git — remote on DagsHub S3
  • Every git commit links to an exact dataset state via .dvc files — making every training run reproducible
  • MLflow on DagsHub — every evaluation run logs metrics, params, artifacts, git SHA, and DVC data hash as tags
  • Model registry — models promoted Staging → Production only when accuracy ≥ 90%

Model: EfficientNet-B0

PyTorch Kaggle GPU ONNX
ZHAW · TSM_MachLeData · Spring 2026 05 / 15
  • EfficientNet-B0 pre-trained on ImageNet — fine-tuned for binary classification (real / fake)
  • Why EfficientNet: compound scaling (depth + width + resolution), stronger feature extraction for photorealistic content than ViT-224
  • Training: Kaggle GPU notebook (external to CI) — 5,000 images, weights versioned via DVC once trained
  • Inference: ONNX Runtime (~0.1s/image), PyTorch retained for GradCAM backprop (~1s)
  • GradCAM: PyTorch gradient-weighted class activation maps — highlights which image regions influenced the prediction
Performance
89.6% Test Accuracy 12,000-image held-out test set
96.2% AUC-ROC Strong discriminative power
0.90 F1 Score Balanced precision / recall

Architecture
  • ONNX Runtime for fast inference — no PyTorch overhead at serve time
  • PyTorch retained alongside ONNX for GradCAM gradient computation
  • GradCAM output: 224×224 heatmap PNG blended with original image, JET colormap (red = high attention)
  • Containerized — model weights bundled in Docker image, no credentials needed at runtime
GradCAM
Gradient-weighted Class Activation Maps — visual explanation of where the model looked in the image when making its decision

Docker & Deployment

Docker Compose GHCR
ZHAW · TSM_MachLeData · Spring 2026 13 / 15
  • docker-compose.yml — spins up API (:8000) + UI (:3000) with a single command
  • Multi-platform build: linux/amd64 + linux/arm64 — runs natively on Apple Silicon (no Rosetta)
  • Model weights bundled in API Docker image — no credentials or DVC pull at runtime
  • docker-compose.prod.yml — production deployment, pulls from GHCR, no build required
  • SQLite volume mount — sessions database persists across container restarts

# Production — pull from GHCR

Pipeline MLOps Outcomes
  • Every run fully reproducible from (git SHA · DVC hash · MLflow run ID)
  • Model versioned, tracked, registered, and deployed — fully automated on push to main
  • Multi-platform Docker images built and pushed to GHCR on each CI pass

Key Observations
  • Model consistently outperforms humans: ~90% vs ~76% on the same images
  • GradCAM reveals model attends to texture artifacts and frequency-domain anomalies in AI images
  • High AUC (96.2%) suggests strong separation even on borderline cases humans find ambiguous
  • EfficientNet-B0 with 5k training images achieves near-human-expert-level discrimination
