The Problem

Problem & Our Answer

The Problem

  • Generative AI makes photorealistic fakes trivially cheap to produce at scale
  • Human visual inspection is no longer reliable — even experts are fooled consistently
  • Detecting AI-generated images requires a system that is deployable, maintainable, and trustworthy
  • A research notebook is not enough — a production pipeline is required

Our Answer

We built an end-to-end MLOps pipeline — not just a model. Every component is versioned, automated, and reproducible by design.

  • Every dataset version is tracked and linked to the model that was trained on it
  • Every experiment is logged — metrics, parameters, and artifacts — so nothing is lost
  • A quality gate prevents any model that does not meet the accuracy threshold from reaching production
  • The full stack deploys with a single command, on any machine
  • New data triggers a new cycle — the pipeline is built to improve over time

Model

EfficientNet-B0 · PyTorch · GradCAM
Architecture
  • EfficientNet-B0 pre-trained on ImageNet (transfer learning)
  • Final classifier replaced: 1 280 → 512 → 1, sigmoid output
  • Input: 224 × 224 RGB, standard ImageNet normalisation
  • Trained on Kaggle GPU (T4) — 5 epochs, AdamW, OneCycleLR
Explainability — GradCAM
  • Gradient-weighted Class Activation Maps on last conv layer
  • Heatmap overlaid on original image at inference
  • PyTorch retained alongside ONNX specifically for backprop

What We Built

Pipeline Over Model
A working MLOps system.
Not a model. Not a notebook. A reproducible, automated, containerised pipeline — with a live application on top.
MLOps Outcomes
  • Reproducible — any commit restores exact data + model via DVC
  • Automated — push to main triggers the full pipeline end-to-end
  • Gated — bad models never reach production (accuracy gate ≥ 85%)
  • Containerised — one command deploys the full stack anywhere
  • Observable — every experiment tracked, every run linked to data version
Model Metrics (SUPPORTING EVIDENCE, NOT THE GOAL)
89.6% Accuracy
96.2% AUC-ROC
0.90 F1 Score
~0.1s ONNX Inference
~1s GradCAM Explain
Limitations & Next Steps
  • Model trained on SD/MJ/DALL-E — may not generalise to newer generators (Flux, GPT-4o)
  • Difficulty tiers assigned by model confidence score, not by image category
  • user_annotation column reserved in SQLite — Label Studio integration planned
  • Next: drift monitoring, retrain on newer generators
